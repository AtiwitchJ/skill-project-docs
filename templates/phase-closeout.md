# Phase N: Outcome and handoff

> **Closed:** record the actual closure date
> **Outcome:** completed, or closed with explicitly accepted limitations

Use this structure for `project/phases/phase-N/deliverable.md`, in the project's configured language. Replace drafting instructions before finalizing. Keep an existing deliverable's useful material and add only missing closeout content. A project status summary belongs under `project/`, not in a user-documentation quadrant.

## Goal and delivered outcome

State what the phase intended to achieve, what actually shipped and any scope difference. Link the source plan and Task evidence; do not reproduce the checklist.

## Delivered work and reading index

| Deliverable or feature | Authoritative file or user guide | What the reader will find |
|---|---|---|

Use links to existing files. Include the relevant user docs, decisions, Task list and phase presentation with descriptive labels.

## Verification and evidence

| Verification performed | Actual result | Report and raw evidence | Limits or unchecked scope |
|---|---|---|---|

State when/where verification ran, its scope and whether data/services were synthetic, mocked or real. Link paired result reports and their raw source where applicable. Do not infer passing tests from artifact availability. If execution tests do not apply, explain the documentation/design checks actually performed.

## Limitations and accepted exceptions

Link unresolved issues and the recorded decision accepting any closure exception. Distinguish accepted limitations from verified completion. If there are none, say so only after checking the source issues/tasks.

## Handoff and next steps

| Remaining work or decision | Issue / next Task | Owner or assignment decision needed |
|---|---|---|

Name the next focus without inventing phases or owners. State whether user documentation changed; if it did not, record why and confirm the existing docs index was reviewed. Ensure `project/README.md` links here and `docs/README.md` links to the relevant user pages before closing.
